## 🌟 Overview
**Malik (MLK)** is a next-generation decentralized liquidity and bridge protocol designed to convert **150+ global fiat currencies** (INR, USD, EUR, GBP, JPY, AED, etc.) and **major cryptocurrencies** (BTC, ETH, SOL) seamlessly through a single, transparent USD-pegged standard.

## 🏗️ Ecosystem Architecture
- `Contracts/MalikToken.sol` — ERC-20 compliant token with on-chain AML blacklist & emergency circuit breaker.
- `Contracts/MalikBridge.sol` — Multi-currency conversion router with a **$10,000/day** anti-money laundering limit.
- `Contracts/MalikLiquidityPool.sol` — Decentralized reserve pool for instant cross-asset liquidity.
- `Contracts/MalikOracle.sol` — Verified real-time price feed oracle with staleness protection.
- `scripts/deploy.js` — Automated ecosystem deployment script.
- `test/MalikSecurity.test.js` — Automated security & compliance test suite.
- `docs/WHITEPAPER.md` — Complete technical & business whitepaper.
