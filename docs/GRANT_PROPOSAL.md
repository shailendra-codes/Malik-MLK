# 💡 Ecosystem Grant & Seed Funding Proposal — Malik (MLK)

## Project Overview
- **Project Name:** Malik (MLK) — Universal Global Currency & Crypto Bridge
- **Lead Architect:** Shailendra Kumar Singh (`@shailendra-codes`)
- **Target Network:** Polygon / Cross-Chain Web3 Ecosystem
- **Core Standard:** `1 MLK = $1.00 USD`

## Problem Statement
Global cross-border remittances and fiat-to-crypto swaps suffer from high intermediary fees (3%–7%), slow settlement times, and weak anti-money laundering (AML) safeguards at the smart contract level.

## Our Solution
**Malik Protocol** introduces a unified liquidity bridge powered by 4 modular smart contracts (`MalikToken`, `MalikBridge`, `MalikLiquidityPool`, `MalikOracle`) featuring:
- Instant conversion routing across **150+ global fiat currencies** and major cryptocurrencies.
- Built-in **On-Chain Blacklisting** and a **$10,000 daily per-wallet limit** to prevent illicit transfers.

## Grant Milestones & Fund Utilization

3. **Milestone 3 (Commercial Scale):** Regulatory registration (**FIU-IND**), KYC API integration, and licensed fiat on/off-ramp liquidity launch.
