# 🤝 Contributing to Malik (MLK) Protocol

Thank you for your interest in building the **Universal Global Currency & Crypto Bridge**!

## How You Can Contribute
1. **Smart Contract Auditing:** Review `MalikToken.sol`, `MalikBridge.sol`, `MalikLiquidityPool.sol`, and `MalikOracle.sol` for gas optimization and security.
2. **Global Currency Support:** Help expand oracle price feeds for regional fiat currencies.
3. **Frontend & UI Improvements:** Enhance the live Web3 converter interface.

## Contribution Rules
- All pull requests must pass strict **AML & Security** checks.
- Do not introduce any centralized backdoors or bypasses to the daily transaction limit (`$10,000/day`).
- Follow clean, well-documented code standards.
